# FaceTask

A simple and elegant task management application built with vanilla JavaScript, Vite, and Tailwind CSS.

## 🚀 Getting Started

### Prerequisites
- Node.js (LTS version)
- npm or yarn

### Installation

1. Clone the repository
```bash
cd FaceTask
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open your browser and visit the localhost URL shown in the terminal

## 📦 Available Scripts

- `npm run dev` - Start development server with hot reload
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint

## 🛠️ Built With

- **Vite** - Next generation frontend tooling
- **Tailwind CSS** - Utility-first CSS framework
- **Vanilla JavaScript** - No framework, pure JavaScript
